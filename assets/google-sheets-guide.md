# Guía rápida para Google Sheets

## Importar un archivo CSV

1. Abre Google Drive.
2. Haz clic en `Nuevo > Carga de archivos`.
3. Selecciona un archivo CSV del repositorio `assets`.
4. Abre el archivo con Google Sheets.
5. Si aparece un problema de columnas, elige `Importar` y revisa el separador adecuado.

## Recomendaciones

- Guarda una copia antes de introducir datos reales.
- Añade una clasificación por cliente y por categoría.
- Usa filtros para revisar ingresos, gastos y proyectos.
- Haz una copia del archivo para cada cliente o proyecto si quieres separar trazabilidad.

## Compatibilidad

Las plantillas están pensadas para ser usadas en:

- Google Sheets
- Ordenadores y navegadores modernos
