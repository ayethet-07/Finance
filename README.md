# OpsFinance Studio

Sitio estático de presentación y demostración para OpsFinance Studio, un proyecto de herramientas de planificación financiera operativa dirigido a profesionales independientes.

## Sitio publicado

- URL: https://ayethet-07.github.io/Finance/
- GitHub Pages: configura **Deploy from a branch**, rama `main`, carpeta `/(root)` en [Settings → Pages](https://github.com/ayethet-07/Finance/settings/pages).
- El archivo de entrada es `index.html` en la raíz.

Tras guardar la configuración o publicar cambios, GitHub Pages puede tardar unos minutos en desplegar el sitio. El estado de la publicación y los errores de compilación aparecen en la pestaña **Actions**.

## Qué contiene

- Página responsive, en español, sin dependencias de CDN.
- Planificador demostrativo que calcula ingresos menos gastos y una reserva elegida por la persona visitante. Los valores se procesan solo en el navegador.
- Información transparente sobre el estado de desarrollo: el sitio no procesa pagos ni ofrece descargas actualmente.

## Alcance y cautelas

El planificador es únicamente educativo. No calcula impuestos, IVA, cuotas a la Seguridad Social, deducciones ni obligaciones legales, y no reemplaza asesoramiento profesional. No introduzcas datos personales o confidenciales.

## Desarrollo local

Abre `index.html` en un navegador o sirve la carpeta con cualquier servidor estático. No se requiere compilación.
